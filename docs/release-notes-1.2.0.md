# Create: Luviteium v1.2.0

## Balance update

- Armor casting now uses vanilla-equivalent material counts: helmet 5, chestplate
  8, leggings 7 and boots 4, with 144 mB and 20 ticks per Luviteium unit.
- Armor keeps 3/7/5/3 defense and now has 1.0 toughness, 0.05 knockback
  resistance and enchantability 9.
- Luviteium tools now use enchantability 9; damage, speed, durability, tier and
  repair behavior are unchanged.
- Biomass Generator fuels are centralized and expanded across wood, plants, crops,
  moss, dried kelp and hay with the documented burn durations. Unsupported fuels
  remain rejected.
- Blank Mold crafting now uses one diamond above three iron ingots. Blank Molds
  stack to 64 and the ten specialized molds remain reusable single-stack items.

Minecraft 1.21.1, NeoForge 21.1.229, Create 6.0.10, mod IDs, registry IDs and
existing world compatibility are unchanged.
